# CollidingWinds

This repository contains animated visualisations of 3D hydrodynamical simulations of colliding stellar winds in massive binary systems, produced as part of my master thesis. The simulations were performed with the smoothed particle hydrodynamics (SPH) code **[PHANTOM](https://github.com/danieljprice/phantom)** (Price et al. 2018) and visualised using the **[SPLASH](https://github.com/danieljprice/splash)** tool (Price 2007).

## Contents

This repository includes the following files:  

- **Animated visualisations** (`.gif`, `.mp4`)  
   Named according to the figure numbers in the thesis, the `.gif` files can be viewed directly in the GitHub browser. The `.mp4` files contain the same animations in a different encoding.  

- **Interactive visualisations** (`.html`)  
  Must be downloaded and opened in a web browser (this has been tested with Firefox and Chrome; it may work with others browsers).
